Documentação do Projeto — Verdejar
1. Sobre o projeto

O Verdejar é um site de vendas voltado para produtos de erva-mate e chimarrão. A ideia é criar uma loja virtual simples, bonita e fácil de usar, onde o cliente possa conhecer os produtos e adicioná-los ao carrinho.

2. Objetivo

O principal objetivo é desenvolver uma experiência de compra simples e organizada, apresentando produtos como ervas, cuias, bombas, mateiras e kits.

3. Tecnologias utilizadas

Para desenvolver o projeto foram utilizadas:

HTML5 — estrutura do site;
CSS3 — visual, cores e organização das páginas;
JavaScript — funcionalidades e interações;
Bootstrap — auxílio na responsividade e no layout.
4. Principais funcionalidades

O site possui:

Página inicial;
Menu de navegação;
Apresentação dos produtos;
Campo de pesquisa;
Carrinho de compras;
Adição e remoção de produtos;
Controle da quantidade de produtos;
Cálculo automático do valor total;
Layout adaptado para diferentes telas.
5. Produtos

Entre os produtos apresentados estão:

Erva-mate;
Cuia de porongo;
Garrafa térmica;
Mateira;
Porta-erva;
Bomba de chimarrão;
Kits para chimarrão.
6. Organização do projeto

O projeto foi separado em três arquivos principais:

index.html
style.css
script.js

As imagens dos produtos ficam organizadas em uma pasta própria chamada img.

7. Como funciona

O usuário entra no site, visualiza os produtos e pode pesquisar aquilo que deseja. Ao escolher um produto, pode adicioná-lo ao carrinho e alterar a quantidade. O sistema calcula automaticamente o valor total da compra.

8. Guia de execução local

Para executar o projeto localmente:

Baixe ou copie a pasta do projeto Verdejar.
Abra a pasta no Visual Studio Code.
Abra o arquivo index.html no navegador.
Para uma experiência melhor durante o desenvolvimento, pode ser utilizado o Live Server do Visual Studio Code.
